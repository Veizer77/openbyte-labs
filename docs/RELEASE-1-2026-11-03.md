## 2. Prosedur pasca-rilis

Semua perintah operator memakai koneksi **direct** (bukan `-pooler`) dan konfirmasi target eksplisit. Tidak ada nilai kredensial yang boleh dicetak.

### 2.1 Migrasi

```powershell
# 1. Set koneksi langsung + target yang disetujui (dari secret manager, jangan dari dokumen)
$env:DATABASE_URI_DIRECT      = "<URI direct>"
$env:DATABASE_MIGRATION_TARGET = "<host>/openbyte_labs"

# 2. Migrasi (keyword MIGRATE)
pnpm db:migrate -- --confirm-target=openbyte_labs --confirm-keyword=MIGRATE
```

### 2.2 Preflight (read-only)

Preflight produksi **wajib** memakai koneksi direct. Sejak perbaikan 3 Nov 2026, perintah ini menolak jatuh ke `TEST_DATABASE_URL` meskipun variabel itu ada di `.env` lokal.

```powershell
$env:DATABASE_URI_DIRECT       = "<URI direct>"
$env:DATABASE_PREFLIGHT_TARGET = "<host>/openbyte_labs"
pnpm db:preflight -- --allow-production --confirm-target=openbyte_labs --confirm-keyword=PRODUCTION-READONLY
```

Harapan: 45 tabel, 20 migrasi, exclusion constraint booking, constraint booking masa depan, 4 marker seed, settings singleton, dan baris seed (availability 20, FAQ 10, kalkulator 13, paket 3).

### 2.3 Sinkronisasi konten dev → produksi

Idempotent (delete-then-insert dalam satu transaksi). Menyalin `media`, `projects`, `project_categories`, `project_technologies`, `technologies`, `categories`, `service_addons`, `testimonials`. **Tidak** menyalin identitas admin, audit, rate limit, seed marker, atau `site_settings`.

```powershell
$env:SYNC_SOURCE_URI     = "<URI dev>"
$env:SYNC_DEST_URI       = "<URI produksi>"
$env:SYNC_SOURCE_TARGET  = "<host dev>/openbyte_labs_dev"
$env:SYNC_DEST_TARGET    = "<host produksi>/openbyte_labs"

# Uji dulu tanpa menulis
pnpm db:sync:content -- --dry-run --confirm-target=openbyte_labs --confirm-keyword=SYNC-CONTENT

# Eksekusi
pnpm db:sync:content -- --confirm-target=openbyte_labs --confirm-keyword=SYNC-CONTENT
```

Baris dicocokkan lewat natural key (slug/key/nama), bukan UUID: kedua branch di-seed terpisah sehingga kategori yang sama punya id berbeda.

### 2.4 Backup

`pnpm db:backup` memerlukan kredensial backup khusus (bucket R2 terpisah + `BACKUP_ENCRYPTION_KEY` ≥32) yang belum tersedia. Selama itu belum diisi, gunakan salah satu:

- **Snapshot Neon** — `create_snapshot` pada branch `main`. Catatan: kuota snapshot project ini 1, jadi hapus snapshot lama sebelum membuat yang baru.
- **Dump lokal** — `pg_dump --format=custom --no-owner --no-privileges`, simpan **di luar repo** (folder `backups/` dan pola `*.dump` sudah git-ignored).

### 2.5 Akun admin

Produksi memakai satu akun owner dengan TOTP aktif. Bootstrap awal hanya boleh lewat `pnpm owner:create` di terminal interaktif (lihat `docs/backend/OWNER_BOOTSTRAP.md`).

**Penting:** secret TOTP tersimpan terenkripsi dengan `BETTER_AUTH_SECRET`. Menyalin akun antar-lingkungan hanya sah bila secret kedua lingkungan identik; skrip `scripts/copy-admin-identity.ts` menolak berjalan bila secret tujuan tidak dapat mendekripsi secret TOTP sumber.

Integrasi Sentry ada di `src/instrumentation.ts` (server) dan `src/instrumentation-client.ts` (klien). Keduanya hanya aktif saat `NODE_ENV=production` **dan** DSN terisi, dengan `beforeSend` yang membuang data pengguna (`src/lib/monitoring.ts`).

### 3.1 Perilaku saat indexing dimatikan

`PUBLIC_INDEXING_ENABLED=false` menghasilkan tiga hal sekaligus, dan ketiganya sudah diverifikasi di produksi pada 3 November 2026:

| Permukaan | Perilaku terverifikasi |
|---|---|
| Header respons | `x-robots-tag: noindex, nofollow` pada semua rute |
| `robots.txt` | `Disallow: /` (seluruh situs) |
| `/sitemap.xml` | HTTP 200 dengan **0 URL** — `src/app/sitemap.ts` baris 15 mengembalikan array kosong sebelum menyentuh database |

Sitemap kosong adalah perilaku yang disengaja, bukan bug. Saat `PUBLIC_INDEXING_ENABLED` diubah ke `true`, sitemap akan berisi halaman statis + proyek publik + layanan + halaman kustom yang `publication_enabled = true`.

## 6. Catatan keamanan

- Kredensial produksi pernah tampil di transkrip sesi agen pada 3 Nov 2026. Rotasi **ditunda atas keputusan pemilik**; catat sebagai risiko diterima dan rotasi sebelum membagikan akses lebih luas.
- Dev-bypass admin (`/api/admin/dev-login`) hanya aktif bila `NODE_ENV !== "production"` **dan** `DEV_ADMIN_QUICK_LOGIN=true`. Variabel itu tidak ada di produksi.
- Smoke produksi kini menolak soft-404: rute negatif wajib berstatus tepat 404, bukan 200 berisi halaman 404.

## Yang belum selesai (jujur)

1. **Persistensi metadata & audit.** `finalizeMediaUpload` mengembalikan metadata; belum menulis ke tabel `media` maupun `audit_logs` karena schema Fase 0 belum memuat tabel media dan DB production belum dimigrasi. N-04 belum tertutup tanpa ini.
2. **Route/Server Action.** Belum ada endpoint; jadi belum ada uji request langsung, origin/CSRF, atau rate limit.
3. **CORS bucket belum dikonfigurasi** — preflight `OPTIONS` dibalas 403. Upload dari browser akan gagal sampai aturan CORS ditambahkan.
4. **URL publik tidak dapat diverifikasi dari mesin ini** — `*.r2.dev` tidak terjangkau dari sandbox (DNS sinkhole), sedangkan endpoint S3 normal. Perlu dicek dari browser pemilik.
5. **Batas memori/waktu serverless** belum diukur (F0-21).

## Penyimpangan kontrak

Kontrak §5 menulis key `media/{year}/{month}/{nanoid}.webp` — pola itu tidak mengakomodasi empat varian per aset. Implementasi memakai `media/YYYY/MM/{mediaId}/{variant}.webp` dan sumber sementara `…/source`. Perlu dikonfirmasi agar kontrak diperbarui.

## Catatan keamanan

- Kredensial hanya dibaca di server (`getStorage`), tidak pernah dikembalikan atau dicetak.
- Signed URL berumur 300 detik; key selalu dari `buildObjectKey`/`buildSourceKey`, tidak dari input browser.
- `getObjectBytes` memeriksa `HEAD` lebih dulu dan menolak objek melebihi batas sebelum mengunduh.
- Berkas tidak valid dihapus dari bucket (bukan dibiarkan).
